# GTOLI Code Factory Pack Final

Pack propre contenant les fichiers utiles du generateur GTOLI.

## Fichiers inclus

1. `files/README.md` - mode d'emploi.
2. `files/gtoli_codegen.py` - generateur principal Markdown + Bash.
3. `files/gtoli_pdf_seed.py` - extracteur PDF vers CSV de depart.
4. `files/exemple_tableau_synoptique.csv` - exemple CSV simple.
5. `files/exemple_tableau_officiel_math_p1.csv` - exemple aligne sur le referentiel math P1.
6. `files/seed_math_p1.csv` - CSV de depart extrait depuis le referentiel PDF P1.
7. `files/exemple_referentiel_mst_p1.md` - mini-referentiel de test.
8. `files/.gitignore` - ignore les caches Python et sorties temporaires.

## Fichier tout-en-un

`PACK_COMPLET_GTOLI_CODE_FACTORY.md` reprend tous les fichiers utiles l'un a la suite de l'autre.
