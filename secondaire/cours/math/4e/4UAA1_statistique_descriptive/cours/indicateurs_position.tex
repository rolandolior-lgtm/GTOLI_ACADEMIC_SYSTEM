\section{Indicateurs de position}

\begin{cadretheorie}
Les indicateurs de position permettent de situer une série statistique.

Les principaux indicateurs sont :
\begin{itemize}
    \item le mode ;
    \item la moyenne ;
    \item la médiane ;
    \item les quartiles.
\end{itemize}
\end{cadretheorie}
